## 真机测试范围

本次没有重新安装到真机，也没有重复首次登录、付费模型调用或长时间运行测试。不能把自动化和打包检查当作真机验收。

0.2.0 已完成的 MOR-M1 / API 26 测试及其限制，见[上一版验证记录](https://github.com/TranswarpDrive/kimi-code-hmos/blob/v0.2.1/docs/RELEASE-VALIDATION-0.2.0.md)。该记录是历史依据，不代表本版新增了设备覆盖。

## 安装与已知限制

- 仅支持 API 26 鸿蒙 PC（2in1），仍需使用自己的证书和设备 Profile 签名。
- 从 0.2.0 升级时沿用原证书覆盖安装，避免卸载清除登录和会话。
- 网页终端受 PTY 限制；ZIP / 网页生成文件的单次导出上限为 32 MiB。
- 多设备、全新账号安装、系统升级、休眠唤醒和长时间后台运行仍未完成独立覆盖。

附件大小与 SHA-256 见发布目录的 release-info.json 和 SHA256SUMS。

## 本次真机范围

设备为 MOR-M1，API 26，平台参数报告 OpenHarmony-7.0.0.109。使用原有本机证书覆盖安装，未卸载应用。

- 升级及冷启动成功，已有登录和会话保留；健康接口返回成功。
- 会话搜索弹窗查询 Python 返回现有测试会话。上游此弹窗匹配标题、工作区和最近提示；正文全文索引另由上述集成测试验证，不混为同一项。
- 连续服务重启后仅保留一组主服务与搜索子进程；旧进程已退出。
- 最小化后进行短时后台检查，主服务及搜索 PID 保持不变，健康接口仍成功。
- 关闭窗口后应用服务与搜索子进程均退出，再次启动成功。
- 连续两次会话 ZIP 导出显示保存完成，第二次自动使用 (1) 后缀，未覆盖第一次导出。文件落在应用可访问的系统下载目录；没有在沙箱外重新读取 ZIP 做 CRC 验证。
- 选择下载目录作为工作目录成功；再次覆盖安装、冷启动后仍恢复为所选目录。测试后恢复默认工作目录。

- GitHub Actions 工作流已配置；本次报告的是本地测试结果，不代表已在 GitHub 执行。
- 仅支持 API 26 鸿蒙 PC（2in1）。网页终端受 PTY 限制；ZIP/blob 下载上限 32 MiB。接收方必须自行签名并具备所需 ACL。

公开附件不含本机签名材料、设备标识、调试截图或个人会话。附件的实际字节数和 SHA-256 见同目录的 release-info.json 与 SHA256SUMS。
